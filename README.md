# Gielinor-Lite
Single-player open-world RPG inspired by RuneScape. Explore, gather, craft gear, and fight.

## Deploy to GitHub Pages

1. Create a new **public** repository on GitHub (e.g. `gielinor-lite`).
2. Upload all files from this folder to the root of the repository (or clone and push).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main** (or master)
   - Folder: **/ (root)**
5. Click **Save**.
6. Wait 1–2 minutes. Your site will be live at:
   ```
   https://YOUR_USERNAME.github.io/gielinor-lite/
   ```

## Add to iPhone Home Screen

1. Open the live URL in **Safari**.
2. Tap the Share button.
3. Choose **Add to Home Screen**.
4. Confirm.

The game will launch full-screen.

## Controls

- Tap the map to walk
- Tap **Interact / Attack** when next to a resource or monster
- Click items in inventory to equip or eat

Progress auto-saves in the browser.
