# Gielinor

Browser-based 3D RPG inspired by classic RuneScape.

## Deploy to GitHub Pages

1. Create a new GitHub repository
2. Upload the contents of this zip
3. Settings → Pages → Deploy from main branch
4. Live at `https://yourusername.github.io/repo-name/`

## Controls

- Tap / click ground to walk
- On-screen D-pad (mobile)
- Interact button near objects
- Save / Export / Import buttons (top-left)
