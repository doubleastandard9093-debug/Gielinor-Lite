# Gielinor

A browser-based 3D RPG inspired by classic RuneScape.

## Play

Open `index.html` in a browser, or deploy to GitHub Pages.

## Controls

- Tap / click the ground to walk
- On-screen D-pad (mobile)
- Interact button near trees, rocks, fish, monsters, or the merchant
- Inventory panel on the right

## Deploy to GitHub Pages

1. Create a new GitHub repository
2. Upload the contents of this folder
3. Go to Settings → Pages → Deploy from main branch
4. Your game will be live at `https://yourusername.github.io/repo-name/`
